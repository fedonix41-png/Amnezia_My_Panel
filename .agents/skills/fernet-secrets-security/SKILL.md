# Безопасность и Шифрование

1. **Секреты серверов**: `password` и `private_key` в БД должны быть зашифрованы алгоритмом Fernet (ключ `MASTER_KEY`). Формат хранения: `"v1:<fernet-token>"`. Использовать модуль `managers/secrets.py`.
2. **Пароли пользователей**: Использовать строго PBKDF2-SHA256. Основной путь — `hash_password` в `app.py` (**600k** итераций, формат `iterations$salt$hash`). Устаревший `hash_password` в `database/repositories.py` использует 100k и формат `salt$hash` — не использовать для новых паролей. `bcrypt` не используется.
3. **API-токены**: Хранятся **только как SHA-256 дайджесты**. Сырое значение возвращается один раз при создании.
4. **CSRF**: Любые небезопасные методы (`POST/PUT/PATCH/DELETE`) защищены CSRF-токеном (кроме bearer-запросов и определенных exempt-роутов).
