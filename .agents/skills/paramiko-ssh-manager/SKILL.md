# Работа с SSH (Paramiko)

1. **Единая точка входа**: Только `managers/ssh_manager.py` (`SSHManager`) открывает SSH-соединения; менеджеры протоколов получают экземпляр `SSHManager` через конструктор. В async-роутах вызовы оборачиваются в `asyncio.to_thread`.
2. **Sudo и секреты**: Пароль sudo передаётся **строго через `stdin`** в `run_sudo_command()` / `run_sudo_script()`, никогда через аргументы командной строки.
3. **Защита от инъекций**: Все пути квотировать через `shlex.quote()`. Пользовательские домены, email, порты и имена контейнеров валидировать до интерполяции в shell-команды.
4. **Host Key Pinning**: Ключи хостов проверяются по схеме TOFU в `_PinningHostKeyPolicy` (`Server.ssh_host_key`).
5. **Тестирование**: В тестах никогда не открывать реальные сокеты — использовать fake SSH / моки на границе `get_ssh` или `SSHManager` (см. примеры в `tests/managers/`).
6. **Глубокий контекст (читать по требованию)**:
   - `docs/terrain/03-infrastructure.md` — устройство `SSHManager`, туннелей и фоновых задач.
