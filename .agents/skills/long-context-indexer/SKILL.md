# Оптимизация контекста

1. **Выбор модели**: Для задач, требующих широкого окна контекста, используйте конфигурацию `gpt-5-mini` (избегайте `gpt-5.4-mini`).
2. **Исключения при парсинге**: При сборке контекста репозитория игнорировать папки `venv`, `.git`, `__pycache__` и любые бинарные файлы.
3. **Фокус**: При анализе обращать внимание на `app.py` (ядро/диспетчеризация), папку `routers/` (API) и `managers/` (бизнес-логика).
