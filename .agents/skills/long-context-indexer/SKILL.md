# Оптимизация контекста

1. **Выбор модели**: Для масштабного анализа используйте модель с широким окном контекста (текущий default — подходит).
2. **Исключения при парсинге**: При сборке контекста репозитория игнорировать папки `venv`, `.git`, `__pycache__`, `.kilo`, `node_modules` и любые бинарные файлы.
3. **Фокус**: При анализе обращать внимание на `app.py` (ядро/диспетчеризация), папку `routers/` (API) и `managers/` (бизнес-логика).
