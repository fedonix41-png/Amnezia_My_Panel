# Управление зависимостями Python

1. **Инструмент**: Использовать строго современный пакетный менеджер `uv`.
2. **Запреты**: Использование `pip` или `poetry` недопустимо.
3. **Синтаксис**:
   - Добавление пакета: `uv add <package>`
   - Синхронизация: `uv sync`
   - Запуск скрипта в окружении: `uv run <script.py>`
