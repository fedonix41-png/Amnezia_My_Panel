# Специфика ОС разработчика

1. **ОС**: Целевая локальная система — Fedora 42 (KDE).
2. **Пакеты**: Для локальных системных зависимостей использовать `dnf`.
3. **Внимание**: Само приложение панели выполняется в Docker-контейнере на базе Debian/Slim (`FROM python:3.12-slim`). Разделять скрипты для хоста и контейнера.
