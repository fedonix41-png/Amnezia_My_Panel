# Telegram Бот

1. **Фреймворк**: Использовать самописный long-polling поверх `httpx`. Библиотека `python-telegram-bot` заявлена, но не используется для логики бота.
2. **Жизненный цикл**: Бот запускается in-process как `asyncio`-таск через `launch_bot(...)`.
3. **Безопасность**: Команды администратора должны быть защищены через `_require_admin(...)`.
4. **Интеграция**: Бот должен использовать те же менеджеры протоколов (через `_get_ssh_and_manager` и `_manager_call`), что и API панели, не дублируя логику SSH.
