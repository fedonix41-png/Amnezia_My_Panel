# Работа с SSH (Paramiko)

1. **Изоляция**: Использовать только инжектированный `SSHManager`. Запрещено прямое использование CLI-команд `ssh`.
2. **Безопасность путей**: При передаче файлов или выполнении команд пути **обязательно** квотировать через `shlex.quote`.
3. **Sudo**: При использовании `run_sudo_command` или `run_sudo_script` пароль передается строго через `stdin` канала SSH, никогда не передавать его в cmdline.
4. **Валидация**: Любые пользовательские строки (домены, email и т.д.) должны валидироваться *до* интерполяции в команды (f-строки).
