# Архитектура FastAPI

1. **Модульность**: Новые эндпоинты добавляются только в пакет `routers/`, а не в `app.py`.
2. **Инъекция зависимостей**: Использовать `Depends(get_db)` для получения сессии базы данных (`AsyncSession`) в роутерах.
3. **Обратная совместимость**: При добавлении роутера в `app.py`, обязательно ре-экспортировать функции хэндлеров и Pydantic-модели как псевдонимы (например, `api_login = auth.api_login`), чтобы не сломать тесты и Telegram-бота.
4. **Контекст**: Для доступа к глобальному состоянию (например, настройкам или туннелям) импортировать `app` как `import app as app_module` внутри роутеров.
