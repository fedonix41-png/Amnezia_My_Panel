# Фильтрация диагностики

1. **Фокус на критичном**: При анализе логов в редакторе Kate, игнорировать некритичные предупреждения Git и LSP.
2. **Приоритет**: Искать строки с `Traceback`, `Fatal error`, `SSHException` или ошибки SQLAlchemy.
3. **Действие**: Не предлагать исправления для варнингов, если они не влияют на успешное выполнение `docker-compose up` или `pytest`.
